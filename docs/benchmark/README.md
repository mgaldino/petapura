# Benchmark de apresentação eleitoral

Registro histórico da pesquisa realizada em 20/10/2026. Inclui o relatório em PDF, capturas, galeria, referências e a adaptação visual do ZEIT para português.

- Relatório: [benchmark_apuracao_eleitoral_2026.pdf](output/pdf/benchmark_apuracao_eleitoral_2026.pdf).
- Capturas e links: [galeria.html](galeria.html).
- Fontes: [referencias.json](referencias.json).

O relatório antecede a restrição definitiva a Presidência/segundo turno e a escolha do desenho Observatório. As decisões atuais estão em [DESIGN.md](../DESIGN.md). As capturas são referências de pesquisa e ficam fora do diretório publicado do site. A tradução do ZEIT é uma adaptação visual identificada, não uma captura de uma página oficialmente traduzida.

O gerador histórico requer Python, reportlab e as fontes Arial no caminho de fontes do macOS declarado no script. Não é uma dependência da aplicação. O PDF de nome terminado em `_v1` preserva a versão anterior do relatório.
